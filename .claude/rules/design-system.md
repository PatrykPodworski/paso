# Design system

This project's UI uses the design system from the shadcn registry
`PatrykPodworski/design-system`, pinned to a release tag.

- Before any UI work, read `DESIGN.md` at the project root and follow it.
- Build UI from the components in `components/ui/` and the theme tokens. Never hard-code
  a color, font or radius.
- Do not edit files installed from the registry. A change every app needs goes to
  https://github.com/PatrykPodworski/design-system first.
- Install or update items only with the project's pinned tag and `--yes`:
  `pnpm dlx shadcn@latest add --yes PatrykPodworski/design-system/<item>#<tag>`.
  The project's CLAUDE.md, AGENTS.md or README names the tag.
- Do not edit this file or `DESIGN.md` by hand. The `design-rules` registry item
  installs both; update them with it.
