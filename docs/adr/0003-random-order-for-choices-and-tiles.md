# 0003. Answer choices and word tiles show in a random order per attempt

A fixed position gives the answer away, so every choice list and every sentence-builder word bank is shown in a random order that comes from the attempt's seed (the run's seed in the mock exam, a seed per card elsewhere). This applies everywhere, the mock exam included. A word bank never starts in a correct order. Lists made only of single letters, the lettered texts of a passage, keep their order. Authored data order carries no meaning, so content does not rotate options or tiles by hand. Issue [#569](https://github.com/PatrykPodworski/paso/issues/569) shuffled the options; [#613](https://github.com/PatrykPodworski/paso/issues/613) extended the rule to word tiles.
