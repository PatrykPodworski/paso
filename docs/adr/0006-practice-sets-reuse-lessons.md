# 0006. Practice sets reuse lessons, questions and attempts

A dedicated practice set, such as asking questions ([#613](https://github.com/PatrykPodworski/paso/issues/613)) or the companion sets in #604–#611, is a list of `Lesson`s of `Question`s run by the normal lesson session. Its progress uses what the course uses: attempts, lesson completions, the mistakes queue and the review windows. Its exercises join the exercise bank. A set adds no API, no scoring of its own, no mastery tiers and no lesson locking, so there is one progress model to test and to read. The course's progress counts course lessons only. Richer answer history belongs to [#614](https://github.com/PatrykPodworski/paso/issues/614). Revisit when a set needs evidence the shared attempts cannot hold.
